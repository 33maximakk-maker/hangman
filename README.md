# Hangman 

Классическая игра «Виселица» (Hangman) на 7 языках программирования. Каждая версия поддерживает:

- **Случайное слово** из встроенного словаря (темы: животные, технологии, программирование)
- **ASCII-графика виселицы** – 6–8 этапов (от начала до полной виселицы)
- **Ввод только букв** – проверка корректности
- **Отображение угаданных букв и оставшихся попыток**
- **Выигрыш / проигрыш** с сообщением
- **Возможность сыграть ещё раз**
- **Подсчёт очков** (побед/поражений) в течение сессии

## Реализации

| Язык | Технология | Особенности |
|------|------------|-------------|
| Python | Console / Tkinter | Только консоль (можно добавить GUI) |
| Go | Console | Цветной вывод, эмодзи |
| Rust | Console | Высокая производительность |
| C# | Console | Кроссплатформенный |
| JavaScript | Web (HTML/CSS) | Браузерная версия |
| TypeScript | Web + классы | Типизированная версия |
| Java | Console | Классический ввод/вывод |
